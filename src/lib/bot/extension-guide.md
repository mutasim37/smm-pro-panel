IMPORTANT — ZEXXA EXTENSION USAGE & TROUBLESHOOTING GUIDE

Please read this guide carefully before using the ZEXXA Extension.

1. BEFORE USING THE ZEXXA EXTENSION

Before activating the extension, open your Lovable project and prepare your complete project requirements.

• Open your Lovable project.
• Switch to Chat Mode.
• Explain your complete project plan, requirements, features, and instructions to Lovable.
• Tell Lovable to prepare everything and continue only when you give the command.
• Use the instruction: “Continue in Build Mode. Start working only when I say Continue.”

Once Lovable is ready, proceed with the extension.

2. AFTER ACTIVATING THE EXTENSION

• Open the browser where the ZEXXA Extension is installed and activated.
• Open your Lovable project in that browser.
• Refresh/reload the Lovable page once.
• Switch the Lovable chat to Build Mode.
• Send “Continue” only once through the official Lovable Chatbox.

After this, allow the extension and Lovable to process the task completely.

Do not send “Continue” repeatedly or send another prompt while the current process is running.

3. CHECK THE RESPONSE

After sending the prompt, check the response/source carefully:

✅ If “Lovable” appears as the response/source, the extension is working correctly.

❌ If your own prompt text appears instead of “Lovable”, refresh the Lovable page and try again.

4. LOVABLE SECURITY & COMPATIBILITY

Due to Lovable's ongoing security and system updates, the ZEXXA Extension may occasionally stop responding or fail to process a prompt correctly.

If this happens:

• Refresh the Lovable page.
• Reload/refresh the ZEXXA Extension.
• Make sure you are using Build Mode.
• If necessary, replace the extension with the latest available version.
• Reload Lovable and try again.

Temporary compatibility issues may occur because of changes to Lovable's security system. This does not necessarily mean there is a problem with your account or the extension.

5. PROMPT TIMING & USAGE LIMIT

For stable operation:

• Use the ZEXXA Extension once every 30 minutes.
• Do not send two extension prompts within the same 30-minute period.
• Sending prompts too frequently may cause the extension to stop responding temporarily.
• Do not send multiple prompts continuously or very quickly.
• Always wait for the current task to finish before using the extension again.

Due to recent security updates, the extension may sometimes work only for a limited number of prompts during a certain period. In some situations, more than 10 prompts may not work properly.

These limitations may change depending on Lovable's current security system and updates.

6. NEW LOVABLE PROJECTS & CREDITS

Creating a new Lovable project may require approximately 1 credit or the applicable amount shown by Lovable.

Once the project is created, follow Lovable's current credit and usage rules.

If your workspace shows:

“Workspace out of credits”
or
“You Have 0 Credits”

the extension cannot process prompts that require available Lovable credits.

Please wait until credits are available or use a workspace/account with the required credits.

7. CAPTCHA / ADDITIONAL VERIFICATION

If Lovable displays:

“Additional verification is required. Please complete the CAPTCHA and try again.”

Complete the CAPTCHA directly on Lovable and then retry the prompt.

If necessary:

• Temporarily disable the ZEXXA Extension.
• Complete the verification directly on Lovable.
• Enable the extension again.
• Refresh Lovable and continue.

8. IMPORTANT USAGE RULES

• Always use the latest ZEXXA Extension version available to you.
• Refresh Lovable after activating or updating the extension.
• Always use the official Lovable Chatbox.
• Use Build Mode when starting the extension process.
• Send “Continue” only once when the project is ready.
• Do not interrupt a prompt after processing has started.
• Do not repeatedly refresh the page while a prompt is running.
• Do not send prompts rapidly.
• Maintain the 30-minute interval between extension uses.
• Make sure your Lovable workspace has sufficient credits.
• Lovable security updates may temporarily affect extension compatibility.

9. RECOMMENDATION FOR NEW CUSTOMERS

If you are using the ZEXXA Extension for the first time, we strongly recommend purchasing the 1-Day Package first.

Test the extension on your own Lovable account and make sure it works properly for your use case.

If everything works as expected, you can then purchase a longer-duration package.
